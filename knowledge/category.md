# Category

## 기본 카테고리 (`prisma/seed.ts`, 테스트 `resetDb`와 동일)

- 지출(9): 주거비, 식비, 생활용품, 교통, 구독, 게임/취미, 쇼핑, 의료/건강, 기타
- 수입(3): 급여, 부수입, 기타 수입

배열 순서가 `sortOrder`. 시드는 upsert라 재실행해도 안전하다. 기본 목록을 바꾸면 `tests/setup/db.ts`도 함께 바꾼다.

## 규칙

| 규칙 | 내용 |
| --- | --- |
| 이름 | trim, 1~30자 |
| 고유성 | 같은 유형 안에서 이름 중복 불가 (보관된 것 포함) → `"같은 이름의 카테고리가 있습니다(보관됨이면 복원하세요)"` |
| 유형 | 생성 시 선택, 이후 변경 불가 (이름만 변경) |
| 정렬 | 새 카테고리는 같은 유형의 `max(sortOrder) + 1`. 목록은 유형 → `sortOrder` → `createdAt` |
| 삭제 | 하드 삭제 없음. 보관(`archivedAt = now`) / 복원(`null`). FK는 `Restrict`. 유일한 예외: 백업 복원은 전체 교체라 카테고리도 지우고 다시 넣는다 ([backup.md](backup.md)) |

## 보관된 카테고리의 동작

| 위치 | 동작 |
| --- | --- |
| 새 거래·새 고정지출 | 선택 불가 |
| 기존 거래·고정지출 수정 | 현재 값이면 유지 가능 |
| 고정지출 자동 등록 | 계속 생성 |
| 최근 카테고리 칩 | 제외 |
| 예산 페이지 | 그 달에 예산이나 지출이 있으면 표시 + "(보관됨)" |
| 대시보드 차트·목록 | 이름 뒤 "(보관됨)" |
| 거래 필터 | 선택 가능 |

카테고리 관리 UI는 `/budgets` 페이지 하단(`CategoryManager`)에 있다.
