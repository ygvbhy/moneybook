# Product Scope

## 제품

- 1인용 개인 가계부 "Moneybook". Notion 가계부 대체 목적.
- 사용자: 관리자 1명 (환경변수 계정). 회원 개념 없음.
- 통화: KRW 단일. 기준 시간대: Asia/Seoul.

## 화면 (NAV_ITEMS 순서)

| 경로 | 이름 | 기능 |
| --- | --- | --- |
| `/` | 대시보드 | 월 요약(전월 대비), 예산 진행(하루 사용 가능 금액), 남은 고정지출, 최근 6개월 추이, 카테고리별 지출 차트(전월 대비), 최근 거래 5건, 결제수단별 지출 |
| `/calendar` | 캘린더 | 월 그리드, 날짜별 거래·예정 고정지출 |
| `/transactions` | 거래 내역 | 필터(유형·카테고리·결제 수단)·검색·정렬, 필터 결과 합계, CSV 내보내기·가져오기 |
| `/recurring` | 고정지출 | 매월 자동 등록 항목 관리 |
| `/budgets` | 예산 | 전체·카테고리 예산, 카테고리 관리 |
| `/login` | 로그인 | |

## 만들지 않는 것 (요청 없이 추가 금지)

- 다중 사용자, 회원가입, 소셜 로그인, 비밀번호 찾기 — 다중 사용자는 추후 별도 마이그레이션으로 다룬다는 결정
- 은행·카드 API 연동, 자동 수집, OCR, AI 분석
- 복식부기, 카드 청구, 자산·부채, 계좌 잔액
- 예산 이월, 이전 달 예산 복사
- 푸시 알림
- 카테고리 하드 삭제, 카테고리 유형 변경
- 고정지출: 수입 항목, 주간·연간 주기, 일시중지·종료월

출처: 로컬 계획 문서 `.claude/plans/personal-ledger-mvp.md`, `recurring-expenses.md`의 제외 범위. MVP 계획은 "정기 결제 자동 생성"을 제외했으나 이후 고정지출 기능으로 범위를 확장했다.
